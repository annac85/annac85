### 💼 Проекты

Ниже — реальные кейсы автоматизации из практики, доведённые до продакшена.

**[app_eml_xls](https://github.com/annac85/app_eml_xls)** — Автоматизация обработки заявок на вебинары
Парсер заявок из email (`.eml`) + генератор PDF-сертификатов. За 4 дня до вебинара вместо ожидаемых 60 заявок пришло 600 — вручную обработать физически невозможно. За 3 дня с нуля собрала рабочий MVP; сейчас цикл обработки одного вебинара сократился с 2 недель до 2–3 часов, инструмент используется в организации до сих пор.
🔗 Подробнее: [cherkasovaanna.ru/projects/webinars](https://cherkasovaanna.ru/projects/webinars/webinars)

**[NMCDCalculator](https://github.com/annac85/NMCDCalculator)** — AI-инструмент для обоснования закупок
Расчёт НМЦД по методу сопоставимых рыночных цен (223-ФЗ) с интерфейсом на PyQt6 и экспортом в Excel. Часть более крупного внутреннего AI-инструмента для подготовки обоснований закупок на базе GigaChat API — заменяет ручной расчёт и исключает ошибки в проверке коэффициента вариации.
🔗 Подробнее: [cherkasovaanna.ru/projects/aizakupki](https://cherkasovaanna.ru/projects/aizakupki/aizakupki)

**[word-to-excel_mirapolis.ru](https://github.com/annac85/word-to-excel_mirapolis.ru)** — Конвертер тестов для LMS Мираполис
Преобразует тесты и опросы из Word в Excel-формат, готовый к импорту на образовательную платформу Мираполис. Задача переноса тестовых материалов, оценённая платформой в 270 000 ₽, решена собственным скриптом: перенос данных занимает 1–2 минуты вместо 10+ дней ручного копирования.
🔗 Подробнее: [cherkasovaanna.ru/projects/lms](https://cherkasovaanna.ru/projects/lms/lms)
